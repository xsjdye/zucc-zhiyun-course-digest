> 浙大城市学院｜课堂笔记
> 整理规则：**一门课一个文件夹，一个课时一个文档** ｜ 最近更新：<YYYY-MM-DD>

---

## 📖 怎么用

1. 打开对应课程的文件夹；
2. 先看 `INDEX.md`（课程索引：课表 / 考核方式 / 总纲）；
3. 每节课的内容都在**一个 `.md` 文档**里——上半部分是**结构化笔记**，下半部分是**附录 · 课堂逐字稿**（原始记录，未校对）；
4. 该课时用到的图片、板书截图、PPT 全帧都在 `图片/<讲次>/` 里，文档内已用相对路径引用，可直接显示。

---

## 📝 每个课时文档的内部结构（统一）

```
1. YAML 元信息（课程 / 讲次 / 教师 / sub_id / 日期 / format / persona）
2. 顶部说明：【课】= 老师讲的（可核对）｜【延】= 视角补的（不作重点依据）
3. 骨架：一张图说清这节课在解决什么问题、各部分怎么咬合
4. 第 N 段（HH:MM–HH:MM）：段内成段叙述，【课】与【延】分层，段末 > 回听
5. 重点（只列有依据的；依据只能来自【课】）
6. 待办 / 遗漏 / 转写勘误（无转写时可省略勘误）
7. 附录 · 课堂逐字稿（原始记录，未人工校对，带时间戳）
8. 底部导航（返回课程索引 ｜ 下一讲）
```

## 📌 每门课索引里另有一份「课程综述」

单讲笔记只回答"这节课讲了什么"。**课程索引**（`<课程名>/INDEX.md`）里要多写一份三段式综述，
回答"这门课值不值得投入、学完能干什么"：

```
知识点整体归纳  ──→  对应专家分析  ──→  导出结果
（可回溯到讲次）      （persona 视角）     （会什么 / 能做什么 / 还缺什么 / 自测题）
```

- 攒够 **2 讲以上**再写第一版，之后每加一讲回填；只有 1 讲时留空，不要硬写
- 第一段必须**可回溯**（每块知识标明挂在哪几讲，去重、指出承重块），第二段是 `persona` 视角的判断、
  **不是课上说的**——与单讲笔记里的【课】/【延】同一条规矩
- 第三段要给**可检验的结论**，不写"了解／熟悉"

## ⚠️ 四条不可破的规则

1. **逐字稿里的同学姓名一律匿名化**（同学A／同学B）。点名、回答、小组分工都算。
   这些当事人从没同意过被公开，风险高于暴露整理者本人。
2. **笔记正文不复制课件原文**，只记位置指针：`sub_id` + 帧时间戳（`created_sec`），复习时回平台看原件。
   帧图可以按下面的「图片/」约定存在**本地库里**，但**不得推到任何公开仓库**。
3. **每新增一个课时文档，必须同时更新**该课的 `INDEX.md` 和本总索引。
   不进索引的笔记等于没写——期末找不到。
4. **课件帧链接免登录就能打开，等于凭证。**
   不要把 `video.hzcu.edu.cn/ai3/ppt/…` 贴进群聊、issue、公开仓库或任何对外位置；
   而且帧图是**整屏截图**，可能带签到名单与同学头像——分享前先看一眼画面里有什么。
