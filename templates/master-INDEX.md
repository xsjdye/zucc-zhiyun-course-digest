## 📖 怎么用

1. 打开对应课程的文件夹；
2. 先看 `INDEX.md`（课程索引：课表 / 考核方式 / 总纲）；
3. 每节课的内容都在**一个 `.md` 文档**里——上半部分是**结构化笔记**，下半部分是**附录 · 课堂逐字稿**（原始记录，未校对）；
4. 该课时用到的图片、板书截图、PPT 全帧都在 `图片/<讲次>/` 里，文档内已用相对路径引用，可直接显示。

---

## 📝 每个课时文档的内部结构（统一）

```
1. YAML 元信息（课程 / 讲次 / 教师 / sub_id / 日期）
2. 顶部导航（返回课程索引）
3. 正文：结构化笔记（分节编号，含要点、板书、考点、待办）
4. 附录 · 课堂逐字稿（原始记录，未人工校对，带时间戳）
5. 底部导航（返回课程索引 ｜ 下一讲）
```

## ⚠️ 四条不可破的规则

1. **逐字稿里的同学姓名一律匿名化**（同学A／同学B）。点名、回答、小组分工都算。
   这些当事人从没同意过被公开，风险高于暴露整理者本人。
2. **笔记正文不复制课件原文**，只记位置指针：`sub_id` + 帧时间戳（`created_sec`），复习时回平台看原件。
   帧图可以按下面的「图片/」约定存在**本地库里**，但**不得推到任何公开仓库**。
3. **每新增一个课时文档，必须同时更新**该课的 `INDEX.md` 和本总索引。
   不进索引的笔记等于没写——期末找不到。
4. **课件帧链接免登录就能打开，等于凭证。**
   不要把 `video.hzcu.edu.cn/ai3/ppt/…` 贴进群聊、issue、公开仓库或任何对外位置；
   而且帧图是**整屏截图**，可能带签到名单与同学头像——分享前先看一眼画面里有什么。
