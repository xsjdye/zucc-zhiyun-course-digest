# zucc-zhiyun-course-digest

> 学在城院 · 智云课堂课后整理助手
>
> 让**任何 AI 助手**帮你把「学在城院」智云课堂上某节课的资料，整理成一份**知识点梳理 + 重点标注**的 Markdown 笔记。

## 这是什么

一个写给 AI 的说明书 + 一个取数脚本。它做的事很具体：

- 你在**任意 AI 助手**里加载它
- 说一句"整理咱们的课：某某课，X 月 X 号那节"
- AI 把这节课的**课件页 + 老师实际说的话**对齐起来，产出一份结构化笔记

笔记里的"重点"不是 AI 猜的——它依据的是老师在哪一页讲了多久、哪里反复展开、哪里明说"要交/要考"。

> ⚠️ 本项目仅供**浙大城市学院同学个人学习**使用，与学校官方无关。请遵守学校相关规定。

### 先说清楚：不同 AI 能自动化的程度不一样

| 你用的 AI | 能自动取数吗 | 怎么走 |
|---|---|---|
| **Qoder** 桌面版 / Cursor / Claude Desktop，且配了浏览器工具 | ✅ 全自动 | 路径 A：AI 在你已登录的页面里跑一次 `zccFetch()` |
| 网页版 / App 版 AI（豆包 / Kimi / 通义 / ChatGPT 等），**不能**操作浏览器 | ✅ 半自动 | 路径 B：你自己在浏览器按 F12 粘一次脚本，把结果粘回给 AI |
| 你不想碰控制台 | ⚠️ 手动 | 路径 C：你自己导内容给 AI，它只负责整理（格式一样，信息少一截） |

**关键点是路径 B**：它让网页版 AI 也能拿到和路径 A 完全一样的数据，
而且**整个过程不经过 AI 任何凭据**——脚本在你自己的浏览器里运行，只借用已登录的会话。

> 所以"零依赖"是指**不用装任何软件**（浏览器自带控制台就是运行环境），
> 不代表所有 AI 都能全自动。差的是"谁去粘那一次脚本"。

## 它能做什么

整理「学在城院」智云课堂上**某一个课时**的资料，产出一份 Markdown 笔记，包含：

| 板块 | 内容 |
|---|---|
| 一、知识点梳理 | 这节课讲了哪些知识点，每个一句话说清，**并给出"帧 + 口述"时间戳依据** |
| 二、重点标注 | ★ 标注老师反复展开、明确说要考要交、课件加粗或单独成页的内容，**写得出依据才标** |
| 三、易混易错点 | 容易混淆的概念对比 |
| 四、课后待办 | 作业、预习要求 |
| 五、本次遗漏 | 没拿到的资料，如实列出（不编造） |
| 附：转写勘误 | 机器听错的术语，列出「原文 → 应为 → 依据」；纠正不了的标「待核」 |

### 它靠的是"课件页 + 口述"时间轴对齐

智云课堂把每页课件的**出现时刻**和**课堂语音转写**都放在同一条时间轴上。
所以能算出"这一页课件，老师实际讲了什么、讲了多久"——这才是课后整理有价值的东西，
而不是把课件文字重新抄一遍。

### ⚠️ 关于「重点标注」，请务必知道

| 拿到了什么 | AI 能判断出的重点 | 可靠度 |
|---|---|---|
| 课件 + 平台转写（**有回放的课通常都有**） | 老师反复展开讲的、明说"要考/要交"的、课件加粗或单独成页的 | ✅ 有依据 |
| 只有课件，转写没生成 | 课件里加粗的、篇幅大的、反复出现的 | ⚠️ **属于推测**，不等于真考点 |

笔记头部有一行**「重点判定依据」**，会写清这次是哪一种。

> 一句话：**这个工具是帮你省事的草稿机，不是考点预言机。**
> 复习请以你自己的课堂记录和课件原文为准，AI 的整理只是辅助参考。
> 另外实测：机器转写会听错术语（`程度`→`成都`、`一人公司`→`艺人化的公司`、`起号`→`洗好`），所以有勘误表这一节。

## 怎么用（三步）

### 第 1 步：在浏览器登录智云课堂

用你自己的账号密码，在**自己的电脑浏览器**里登录 <https://classroom.hzcu.edu.cn/>。

> 🔒 **你的密码只存在你自己的设备上。** 本 skill 全程不接触、不记录、不上传你的账号密码，也不需要 token。

### 第 2 步：把它装进你的 AI

**最省事的做法（任何 AI 通用）**：打开 [`PROMPT.md`](PROMPT.md)，**全选复制**，粘贴到你 AI 对话框的最开头。

**各平台的具体做法**：

| 你的 AI | 怎么装 |
|---|---|
| 网页版助手（豆包 / Kimi / 通义 / ChatGPT 网页版等） | 把 `PROMPT.md` 全文粘贴到对话开头 |
| 手机 App 版助手 | 打开 `PROMPT.md`，长按全选复制，粘进对话框开头 |
| Qoder | 让 AI 读取本仓库的 `SKILL.md`，或把内容粘进对话开头 |
| Cursor / Claude Desktop 等支持 Skill 的 | 把 `SKILL.md` 放进其 skill / 规则目录，或让 AI 直接读该文件 |

> 记不住就一句话：**把 `PROMPT.md` 整个复制给 AI**，准没错。
> 走路径 B 的话，另外把 [`scripts/fetch-lesson.js`](scripts/fetch-lesson.js) 也留在手边（一个文件，复制即用）。

### 第 3 步：说一句话

```
整理咱们的课：<你的课程名>，<YYYY-MM-DD> 那节
```

AI 会先给你一段安全告知，确认你已登录，然后确认是哪一节课。之后：

- **路径 A**（AI 能操作浏览器）→ 它在你已登录的页面里跑 `zccFetch()`，一次拿到课件帧 + 转写 + 元信息
- **路径 B**（AI 不能操作浏览器）→ 它让你自己在浏览器 F12 里粘一次脚本，`copy(await zccFetch(...))`，结果粘回给它
- **路径 C**（你不想碰控制台）→ 你导内容给它，它只整理

三条路**产出的笔记格式完全一样**，差别只在拿到的信息量。

## 路径 B 具体怎么做（网页版 AI 也能全自动取数）

这一步看着"程序员"，其实只是三次复制粘贴：

1. 在**已登录**的 <https://classroom.hzcu.edu.cn/> 页面，按 `F12`（Mac 上是 `⌥I`）→ 切到 **Console / 控制台**
2. 打开 [`scripts/fetch-lesson.js`](scripts/fetch-lesson.js)，**全选复制**，粘到控制台里，按回车
3. 再输入下面这行，按回车：
   ```js
   copy(await zccFetch('2026-10-15', '数字媒体'))
   ```
4. 结果已经在你的剪贴板里了 → 直接 `⌘V` 粘给 AI

不知道日期或课程全名？第二个参数传空字符串，它会把你那天有哪些课列出来：

```js
await zccFetch('2026-10-15', '')          // 列出当天课程
await zccFetch('2026-10-15', '', {pick: 1})  // 选第 2 节
await zccFetch('2026-10-15', '数字媒体', {maxSec: 900})  // 只要前 15 分钟
```

**两个必须知道的限制**（实测）：

- 只能在 `classroom.hzcu.edu.cn` 域下运行。在城院其它域名（比如 `education.hzcu.edu.cn`）里跑会直接报 `Failed to fetch`
- 脚本只借用你已登录的 Cookie 发请求，**不读取、不打印任何 token**

想让 AI 自己去读页面（路径 A），你用的必须是 **AI Agent 类工具**并提前配好浏览器能力：

| 工具 | 要配什么 |
|---|---|
| Qoder 桌面版 | 开启 Browser Connector（浏览器连接） |
| Cursor | 安装并配置 Playwright 类 MCP 服务 |
| Claude Desktop | 配置浏览器自动化类 MCP 服务 |

接口字段、时间轴对齐方式、全部已知坑，写在 [`scripts/api-contract.md`](scripts/api-contract.md)。

## 合规与隐私（分享 / 上传前必读）

### 🔴 最容易出事的一条：同学的姓名

课堂逐字稿里**天然含点名环节和同学发言的真实姓名**——这些同学从没同意过被公开，泄露他们比泄露你自己严重得多。

| 必须做 | 说明 |
|---|---|
| 点名 / 同学回答 / 小组分工里的姓名 → 匿名化为「同学A」 | **整理时就做**，别等上传前才补救 |
| 含他人姓名的逐字稿**不得**推到任何公开位置 | 教室编号、精确课表、选课人数同理 |
| `examples/` 只放虚构数据 | 本仓库里的示例全部是编的 |

### 课件版权与"链接即凭证"

课件是老师的作品。本工具**不保存课件原文与原图**，只记「位置指针」：`sub_id` + 帧时间戳，复习时回平台看原件。

🔴 **课件帧的 URL 免登录就能打开**（实测：不带任何 Cookie 返回 200）。这条在本仓库里是作为**风险**记录的，不是作为技巧：

- 它意味着**链接本身就是访问凭证**，平台无法校验点链接的人是否选了这门课
- 所以：**不要把 `video.hzcu.edu.cn/ai3/ppt/…` 贴进仓库、issue、群聊或任何公开位置**
- 为整理而下载到本地的帧图，读完即删，且**不要放在仓库目录内**（放 `output/`，已被 `.gitignore` 排除）
- 帧图是**整屏截图**，可能带签到名单、同学头像、老师浏览器标签页 → 一律不上传
- 这个行为该被修正的话，请把 [`scripts/api-contract.md`](scripts/api-contract.md) 第 2 节发给学校信息中心判断，**不要自己去验证边界**

### 学校内部接口

仓库中出现的 `yjapi.hzcu.edu.cn` 等端点，**仅限本校学生访问自己的课程数据**：

- 调用靠你**已登录浏览器的 Cookie**，别人拿不到你的数据
- 这些路径不是逆向得到的秘密，而是学校下发给每个登录学生的前端 JS 里的明文
- 不得用于他人、不得高频并发、不得批量抓取
- **本工具只做你本人登录后本来就能看到的事。** 换别人的 `user_id`、枚举不属于自己的 `sub_id` 属于未授权的访问控制测试——**本仓库没做过，也不建议任何人做**
- 若学校提出要求，会立即移除相关说明

### 凭据

- **本工具不需要 token，也不该去拿 token。** 实测只要 Cookie 就能取数。
  浏览器里的资源列表 URL **会带出完整 token**，一旦进入对话、日志或截图就收不回来 → **不要 dump 资源列表**
- 任何凭据**绝不写进会提交的文件**；`config/`、`cookies*.json` 已被 `.gitignore` 排除
- `privacy-keywords.txt`（你自己的敏感词清单）同样永不提交
- 本工具不代登录、不保存密码

### 上传前必跑这两条

```bash
python3 scripts/privacy-scan.py --selftest   # 先确认扫描器本身有效
python3 scripts/privacy-scan.py              # 再扫仓库，退出码非 0 就不要上传
```

## 常见问题

**Q：我没有编程基础，能用吗？**
能。不用装任何软件。路径 A 全自动；路径 B 只是"复制两次、粘贴两次"，照 [`scripts/fetch-lesson.js`](scripts/fetch-lesson.js) 顶部注释做就行。

**Q：任何 AI 都能用吗？**
整理环节是的。取数环节分三档（见上文表格），差别只是"谁去粘那一次脚本"，不是"能不能拿到数据"。

**Q：我要把密码给 AI 吗？**
**不要。** 正确做法是你自己先在浏览器登录，然后要么 AI 复用你已登录的会话，要么你自己在控制台跑脚本。
两条路都不把凭据交给 AI。任何要你交出密码的做法都不对。

**Q：整理结果准确吗？**
**仅供参考**，尤其"重点标注"。机器转写会听错术语，笔记里的「转写勘误」表就是为此存在的。
**你自己的理解和课堂记录优先。**

**Q：还要我自己录音、自己转写吗？**
**通常不用。** 智云课堂**有回放的课，平台自带语音转写**，`zccFetch()` 直接就能拿到（实测一节课 1869 段 / 35410 字）。
只有平台转写没生成时，才需要本地转写兜底 —— 选模型前**要先体检电脑**（内存 / 芯片 / 有无独显）：
见 [`scripts/asr-setup.md`](scripts/asr-setup.md)。

**Q：为什么我跑脚本报 `Failed to fetch`？**
因为你不在 `classroom.hzcu.edu.cn` 域下。城院其它域名（如 `education.hzcu.edu.cn`）会被跨域策略拦掉。

**Q：课件是 PPT 文件，AI 读不到正文吧？**
平台把每页课件截成图（1280×720），并且记录了每页出现的时刻。
所以 AI 是**读图**而不是解析 `.pptx`——有视觉能力的 AI 不需要装 OCR。

## 遇到问题怎么办

| 情况 | 怎么办 |
|---|---|
| AI 说"我不能打开浏览器" | 正常。走路径 B：你自己在 F12 控制台粘一次脚本，结果粘回给它 |
| AI 要你提供账号密码 | **不要给。** 提醒它：正确做法是复用已登录会话或让用户自己跑脚本。若它坚持要，换个 AI 用 |
| 脚本报 `Failed to fetch` | 换到 `classroom.hzcu.edu.cn` 页面再跑 |
| 课件只拿到 10 条 | 你传了 `page` / `per-page`。**不传分页参数会一次返回全部** |
| 逐字稿糊成几大块 | 合并规则缺跨度上限，用 `fetch-lesson.js` 里的规则（间隔≤2s 且 跨度<40s 且 字数<220） |
| `transcript.available` 是 false | 该课转写未生成或无回放 → 走本地转写兜底，或如实标注"仅基于课件" |
| 一节课内容太多，只整理了一部分 | 用 `{maxSec: 900}` 先跑前 15 分钟；或分批按时间段整理 |
| AI 整理的知识点不对 / 漏了 | 把对应帧图补给它重做；笔记仅供参考 |
| 想要更简 / 更详细 | 直接说"要精简版"或"要详细版"，它会切换详略档位 |
