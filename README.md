# zucc-zhiyun-course-digest

> 学在城院 · 智云课堂课后整理助手
>
> 让**任何 AI 助手**帮你把「学在城院」智云课堂上某节课的资料，整理成一份**知识点梳理 + 重点标注**的 Markdown 笔记。

## 这是什么

一个**零依赖**的 AI Skill（技能）。它本质上是一份写给 AI 的说明书：

- 你在**任意 AI 助手**里加载它
- 用一句自然语言说"整理咱们的课：某某课"
- AI 就按固定流程，把这节课的内容整理成一份结构化笔记

**不需要安装任何软件**，不限 AI 平台——本机 AI（Qoder / Cursor / Claude Desktop）和网页版 AI 都能用。

> ⚠️ 本项目仅供**浙大城市学院同学个人学习**使用，与学校官方无关。请遵守学校相关规定。

### 先说清楚：不是所有 AI 都能「自动扒」

这点很重要，免得你试了以为工具坏了：

| 你用的 AI | 能不能自动打开智云课堂 | 实际怎么用 |
|---|---|---|
| 豆包 / Kimi / 通义 / ChatGPT 等**网页版、App 版** | ❌ **不能**，它们碰不到你的浏览器 | 你把课件内容复制或截图发给它，它负责整理 |
| **Qoder** 桌面版等 AI Agent | ✅ 能，但要连上浏览器 | 可自动读你已登录的页面 |
| Cursor / Claude Desktop | ⚠️ 能，但要先配浏览器类 MCP 工具 | 见下方「要自动化，先配这些」 |

所以这个 skill 有两条路，**两条都能出同样格式的笔记**：

- **主路径（人人可用）**：你导内容 → AI 整理
- **进阶路径（需 AI Agent）**：AI 自己去读你已登录的页面

> **「零依赖」的意思是不用装软件，不代表任何 AI 都能自动化。**

## 它能做什么

整理「学在城院」智云课堂上**某一个课时**的资料，产出一份 Markdown 笔记，包含：

| 板块 | 内容 |
|---|---|
| 一、知识点梳理 | 这节课讲了哪些知识点，每个一句话说清 |
| 二、重点标注 | ★ 标注课件中加粗的、篇幅大的、反复出现的内容，并给出理由 |
| 三、易混易错点 | 容易混淆的概念对比 |
| 四、课后待办 | 作业、预习要求 |
| 五、本次遗漏 | 没拿到的资料，如实列出（不编造） |

### ⚠️ 关于「重点标注」，请务必知道

AI 只能看到你提供的资料。而"老师嘴上说这个要考"这件事，**通常不写在课件上**。

| 你给了什么 | AI 能判断出的重点 | 可靠度 |
|---|---|---|
| 只有课件 / 讲义 | 课件里加粗的、篇幅大的、反复出现的 | ⚠️ **属于推测**，不等于真考点 |
| 课件 + 课堂录音（或录音转出的文字） | 再加上老师口头强调、反复讲解、明确说"要考"的内容 | ✅ 明显更准 |

笔记里会有一行**「重点判定依据」**，写清这次是基于什么判断的。

> 一句话：**这个工具是帮你省事的草稿机，不是考点预言机。** 复习请以你自己的课堂记录和课件原文为准。

## 怎么用（三步）

### 第 1 步：在浏览器登录智云课堂

用你自己的账号密码，在**自己的电脑浏览器**里登录「学在城院」智云课堂。

> 🔒 **你的密码只存在你自己的设备上。** 本 skill 全程不接触、不记录、不上传你的账号密码。

### 第 2 步：把它装进你的 AI

**最省事的做法（任何 AI 通用）**：打开 [`PROMPT.md`](PROMPT.md)，**全选复制**，粘贴到你 AI 对话框的最开头。这一步做完就能用了。

**各平台的具体做法**：

| 你的 AI | 怎么装 |
|---|---|
| 网页版助手（豆包 / Kimi / 通义 / ChatGPT 网页版等） | 把 `PROMPT.md` 全文粘贴到对话开头 |
| 手机 App 版助手 | 打开 `PROMPT.md`，长按全选复制，粘进对话框开头 |
| Qoder | 让 AI 读取本仓库的 `SKILL.md`，或把内容粘进对话开头 |
| Cursor / Claude Desktop 等支持 Skill 的 | 把 `SKILL.md` 放进其 skill / 规则目录，或让 AI 直接读该文件 |

> 记不住就一句话：**把 `PROMPT.md` 整个复制给 AI**，准没错。

### 第 3 步：说一句话

对 AI 说：

```
整理咱们的课：<你的课程名>
```

AI 会先给你一段安全告知，确认你已登录，然后问你具体是哪一节课。之后它会：

- 如果你用的 AI 能操作浏览器 → 直接读你已登录的智云课堂页面
- 如果不能 → 它会请你把课程内容贴过来

最后给你一份笔记。

## 要自动化，先配这些（可选）

想让 AI 自己去读智云课堂页面，你用的必须是 **AI Agent 类工具**（能在你电脑上操作浏览器的那种），并且要提前配好浏览器能力：

| 工具 | 要配什么 |
|---|---|
| Qoder 桌面版 | 开启 Browser Connector（浏览器连接），让 AI 能操作你的浏览器 |
| Cursor | 安装并配置 Playwright 类 MCP 服务 |
| Claude Desktop | 配置浏览器自动化类 MCP 服务 |

**两个前提**：

1. 你要在自己的浏览器里**先登录**智云课堂——AI 不碰你的密码
2. AI 要有读取网页 / 截图的工具权限

另外要知道一个现实：**智云课堂的课件多为 `.pptx` / `.pdf` 文件**，页面上通常只有文件名。AI 抓到的往往是文件列表而不是正文，所以**你把课件下载或导出后交给 AI，常常比让它"读页面"更靠谱**。

没配这些也不影响使用——走"你贴内容、AI 整理"的路径即可，见 [`examples/fallback-example.md`](examples/fallback-example.md)。

## 常见问题

**Q：我没有编程基础，能用吗？**
能。这个项目**不需要安装任何软件**，你只要把 `PROMPT.md` 复制给 AI 就行。

**Q：任何 AI 都能用吗？**
是的。设计目标就是"任何 AI 无障碍使用"。能力弱的 AI 走"你贴内容、它整理"的路径，一样出结果。

**Q：我要把密码给 AI 吗？**
**不要。** 正确做法是你自己先在浏览器登录，AI 只需读取已登录的页面。任何让你交出密码的做法都不对。

**Q：整理结果准确吗？**
AI 整理的笔记**仅供参考**，尤其是"重点标注"，请**务必自己核对**课件原文。

**Q：支持录音/视频吗？**
本 skill 自己不处理音频，但**你可以先在本地把录音转成文字**，再连同课件一起交给 AI——这样「重点标注」才有真依据。
选模型之前**要先体检电脑**（内存 / 芯片 / 有无独显），不同配置该装的完全不同：见 [`scripts/asr-setup.md`](scripts/asr-setup.md)。

## 遇到问题怎么办

| 情况 | 怎么办 |
|---|---|
| AI 说"我不能打开浏览器" | 正常。它走的是降级路径——你把课件文字或截图发给它就行，见 [`examples/fallback-example.md`](examples/fallback-example.md) |
| AI 要你提供账号密码 | **不要给。** 提醒它：正确做法是你自己先登录，它只读已登录页面。若它坚持要，换个 AI 用 |
| AI 读不了 PPT / PDF 文件 | 把课件导出成 PDF、图片，或直接复制里面的文字给它 |
| 一节课内容太多，只整理了一部分 | 让它分批读、读完再合并；或你分几次把内容发它 |
| AI 整理的知识点不对 / 漏了 | 把课件原文补给它让它重做；笔记本身仅供参考 |
| 想要更简 / 更详细 | 直接说"要精简版"或"要详细版"，它会切换详略档位 |
| AI 说"打不开智云课堂 / 要登录" | 你需要在**自己电脑的浏览器**里先登录智云课堂，再让 AI 读 |
