# zucc-zhiyun-course-digest

> **学在城院 · 智云课堂课后整理助手**
> 让**能操作浏览器的 AI 助手**（Qoder / Cursor / Claude Desktop 等）把一节课堂整理成带依据的笔记。
> 你只需登录一次，取数、读课件、对齐时间轴、出笔记全部由 AI 做完。

## 30 秒上手

**1. 拿到文件**（不会 git 也没关系）

- 下整个仓库：打开仓库页 → 绿色 `Code` → `Download ZIP`；或直接下
  <https://github.com/xsjdye/zucc-zhiyun-course-digest/archive/refs/heads/main.zip>
- 只要两个文件：[`PROMPT.md`](PROMPT.md) 和 [`scripts/fetch-lesson.js`](scripts/fetch-lesson.js)，浏览器里打开、右上角复制原文

**2. 在自己的电脑浏览器登录** <https://classroom.hzcu.edu.cn/>

**3. 粘给 AI 并说一句话**：把 `PROMPT.md` 全文粘到对话开头，然后

```
整理咱们的课：<课程名>，<YYYY-MM-DD> 那节
```

第一次用如果 AI 打开的浏览器里没登录，它会请你**在它打开的那个窗口**里登录一下——正常，登一次就不用再登。

🔒 **你的密码只存在你自己的设备上。** 本工具全程不接触、不记录、不上传账号密码，也不需要 token。

## 它凭什么能标出重点

多数"AI 整理课件"只能看课件写了什么，而**课件上通常不写"这个要考"**。智云课堂把**每页课件的出现时刻**和**课堂语音转写的起止秒数**放在同一条时间轴上，所以能算出"这一页，老师实际讲了什么、讲了多久"：

![帧与转写的时间轴对齐机制](assets/timeline-align.svg)

于是重点判定有依据，而不是靠版式猜：

| 拿到了什么 | 能判断出的重点 | 可靠度 |
|---|---|---|
| 课件 + 平台转写（**有回放的课通常都有**） | 反复展开讲的、明说"要考/要交"的、课件加粗或单独成页的 | ✅ 有依据 |
| 只有课件，转写没生成 | 课件里加粗的、篇幅大的、反复出现的 | ⚠️ **属于推测** |

> 一句话：**这是帮你省事的草稿机，不是考点预言机。** 复习以你自己的课堂记录和课件原文为准。
> 机器转写一定会听错术语（实测 `程度`→`成都`、`一人公司`→`艺人化的公司`、`起号`→`洗好`），所以笔记自带勘误表。

## 笔记包含什么

单个课时：**骨架 → 分段内容 → 重点 → 待办 → 遗漏 → 转写勘误**（六块）。

- **骨架**：一张图说清这节课在解决什么问题、各部分怎么咬合——先给主线，再落细节
- **分段内容**：每段约一节课 40 分钟，段内成段叙述；`【课】`是老师讲的（可回平台核对），`【延】`是以行业视角补的（**不作为重点依据**）
- 时间粒度按段，秒级指针收在每段末尾的 `> 回听：…`，要回听时再展开

整门课另有一份**课程综述**（在 `course-INDEX.md`）：`知识点整体归纳 → 对应专家分析 → 导出结果`——
回答的是"这门课值不值得投入、学完能干什么"，而单讲笔记回答的是"这节课讲了什么"。

要长期归档进 Obsidian 的话，`templates/` 里有三件套：一讲一份、一门课一份索引、全部课程一份总索引。
**归档必须同时更新两级索引**——只写课时文档不更新索引，是这套笔记最容易烂掉的地方。

## AI 能不能操作浏览器，决定了走哪条路

**能**（Qoder 开 Browser Connector；Cursor / Claude Desktop 配浏览器类 MCP 服务）→ AI 在你已登录的页面里跑
[`scripts/fetch-lesson.js`](scripts/fetch-lesson.js)，一次拿到课件帧 + 平台转写 + 元信息：

```js
await zccFetch('2026-10-15', '数字媒体')                  // 整节
await zccFetch('2026-10-15', '数字媒体', {maxSec: 900})    // 只要前 15 分钟
```

**不能**（网页版 / App 版 AI 碰不到你的浏览器）→ 它取不到数据，只能整理你自己导给它的内容，
重点判定降级为推测。想要全自动，就得换一个能操作浏览器的 Agent 工具。

> "零依赖"指的是**不用装任何软件**——脚本的运行环境就是浏览器本身。
> （`fetch-lesson.js` 也可以由用户自己在控制台跑一次来喂数据，但那是**进阶备选**：
> 把操作推回给用户跟"方便"是反的。做法留在 [`scripts/README.md`](scripts/README.md)。）

## 隐私与合规（分享 / 上传前必读）

### 🔴 最容易出事的一条：同学的姓名

课堂逐字稿里**天然含点名环节和同学发言的真实姓名**——这些同学从没同意过被公开，泄露他们比泄露你自己严重得多。

- 点名 / 同学回答 / 小组分工里的姓名 → **整理时就**匿名化为「同学A」
- 含他人姓名的逐字稿**不得**推到任何公开位置；教室编号、精确课表、选课人数同理
- `examples/` 只放虚构数据（本仓库里的示例全部是编的）

### 🔴 第二条：课件帧链接免登录就能打开

实测：不带任何 Cookie，课件帧 URL 返回 200。**这条在本仓库里是作为「风险」记录的，不是技巧**——
它意味着链接本身就是访问凭证，平台无法校验点链接的人是否选了这门课。所以：

- **不要把 `video.hzcu.edu.cn/ai3/ppt/…` 贴进仓库、issue、群聊或任何公开位置**
- 为整理而下载到本地的帧图，读完即删，且**不要放在仓库目录内**（放 `output/`，已被 `.gitignore` 排除）
- 帧图是**整屏截图**，实测里出现过签到二维码、签到进度、老师浏览器标签页与任务栏 → 一律不上传
- 认为该修正的话，请把 [`scripts/api-contract.md`](scripts/api-contract.md) 第 2 节发给学校信息中心，**不要自己去验证边界**

### 凭据与使用边界

- **本工具不需要 token，也不该去拿 token。** 实测只要 Cookie 就能取数。
  浏览器资源列表 URL **会带出完整 token**，一旦进对话、日志或截图就收不回来 → **不要 dump 资源列表**
- 任何凭据**绝不写进会提交的文件**；`config/`、`cookies*.json`、`privacy-keywords.txt` 已被 `.gitignore` 排除
- **只做你本人登录后本来就能看到的事。** 换别人的 `user_id`、枚举不属于自己的 `sub_id` 属于未授权访问控制测试——**本仓库没做过，也不建议任何人做**
- 不高频、不并发、不批量抓取；仓库里的接口路径是学校下发给每个登录学生的前端 JS 里的明文，不是逆向得到的秘密
- **若学校提出要求，会立即移除相关说明**

### 上传前必跑

```bash
# macOS / Linux
python3 scripts/privacy-scan.py --selftest   # 先确认扫描器本身有效
python3 scripts/privacy-scan.py              # 再扫仓库

# Windows（没有 python3 这个命令，用 python，路径用反斜杠）
python scripts\privacy-scan.py --selftest
python scripts\privacy-scan.py
```

退出码非 0 就**不要上传**。Windows 若显示乱码，先 `chcp 65001`（不影响判定结果）。
它只看"git 认为会被上传的文件"，所以 `output/` 里的真实笔记不会误报；但你把真实笔记挪进 `examples/` 就会被拦住。

## 常见问题与排错

| 情况 | 怎么办 |
|---|---|
| **登录页闪一下就没了** | AI 在重定向途中**又导航了一次**。别再导航，让登录页停住，你自己输完账号密码，再让 AI 重新判定 |
| AI 报 `ERR_ABORTED` / `chrome-error` 打不开 classroom | **不是站点挂了**。未登录时 classroom 返回 200 + 前端外壳，由页面自己的 JS 跳去 CAS，工具把这一跳的中断误报成了失败 |
| 登录页报 `ERR_TUNNEL_CONNECTION_FAILED` | `ca.hzcu.edu.cn` **只有 HTTP，没有 HTTPS**。确认地址栏是 `http://`；不行就关掉浏览器"始终使用安全连接" |
| AI 的浏览器里没有登录态 | 正常，第一次用都会这样。在它打开的登录页里登一次就行，之后不用再登 |
| 脚本报 `Failed to fetch` | 你不在 `classroom.hzcu.edu.cn` 域下。城院其它域名（如 `education.hzcu.edu.cn`）会被跨域策略拦掉 |
| AI 说"我不能打开浏览器" | 那是网页版 / App 版 AI 的限制，它取不到数据，只能整理你导给它的内容 |
| **AI 要你提供账号密码** | **不要给。** 正确做法是 AI 复用已登录会话，或你自己在浏览器里操作。任何要你交出密码的做法都不对 |
| 看不到 AI 打开的浏览器窗口 | 让它切到可见 / 前台窗口；切不了就说明这个 AI 走不了主路径，只能降级 |
| 课件只拿到 10 条 | 你传了 `page` / `per-page`。**不传分页参数会一次返回全部** |
| 逐字稿糊成几大块 | 合并规则缺跨度上限，用 `fetch-lesson.js` 里的规则（间隔≤2s 且 跨度<40s 且 字数<220） |
| 读 `transcript.available` 报错 | 先看返回里的 `ok`：`false` 表示没匹配到课（只有 `error` 字段，没有 `transcript`）|
| `transcript.available` 是 false | 该课转写未生成或无回放 → 走本地转写兜底，或如实标注"仅基于课件" |
| 一节课太长、整理不完 | 用 `{maxSec: 900}` 先跑前 15 分钟；或按时间段分批 |
| 想要更简 / 更详细 | 直接说，AI 会调整分段密度 |

**换一台电脑第一次跑，先确认这四件事**：① AI 打开的浏览器窗口你能看到吗 ② 页面停在 `classroom` 域就是已登录、跳到 `ca.hzcu.edu.cn` 就是没登录 ③ 地址栏必须是 `classroom.hzcu.edu.cn` ④ 有没有 Python（**只影响自检脚本，取数不依赖它**）。

接口字段与全部已知坑写在 [`scripts/api-contract.md`](scripts/api-contract.md)。
