# 笔记模板

整理输出的标准模板。同学也可以直接复制本模板，自己往里填。

```markdown
# <课程名> · <课时 / 章节名>

> 整理时间：<YYYY-MM-DD> ｜ 来源：学在城院·智云课堂 ｜ 整理方式：AI 辅助
> 重点判定依据：<课件文字 + 课堂转写> ／ <仅课件文字，未拿到转写，以下 ★ 属推测>
> `sub_id` `<值>`｜转写 <N> 段 / <N> 字｜课件帧 <N> 帧

## 一、知识点梳理
- **<知识点 1>**：一句话说明
  - 依据：帧 <HH:MM> + 口述 <HH:MM>–<HH:MM>
- **<知识点 2>**：一句话说明
  - 依据：帧 <HH:MM>（该页停留很久但老师只一句带过 → **权重低**）

## 二、重点标注
- ★ <重点 1>（只写你**看得到**的依据：老师反复展开讲 / 明确说"要考""要交" / 课件加粗或单独成页 / 目录与小结都出现）
- ★ <重点 2>

## 三、易混易错点
- **<A> vs <B>**：区别是……

## 四、课后待办
- [ ] <作业 / 预习要求>

## 五、本次遗漏
- <未获取到的资料，如某段录音、某页课件；如无则写"无">

## 附：转写勘误
| 转写原文 | 应为 | 判定依据 |
|---|---|---|
| <错词> | <应为> | 课件文字 / 上下文 / 同音 |
| <错词> | 待核 | 无佐证，需回听录音 |
```

## 填写说明

| 板块 | 怎么写 |
|---|---|
| 头部 `sub_id` | 位置指针。不复制课件原文，凭 `sub_id` + 时间戳回平台看原件 |
| 一、知识点梳理 | 用自己的话说清"是什么"，别照抄课件原文；**每条给出时间戳依据**，没有依据的不要硬凑 |
| 二、重点标注 | 必须**给出看得到的依据**，不能只打一个 ★；写不出依据的就别标成重点 |
| 三、易混易错点 | 只有确实存在易混概念时才写；没有可省略 |
| 四、课后待办 | 课程有作业/预习要求才写；没有可省略 |
| 五、本次遗漏 | **如实填写**，拿不到就写拿不到，**绝不编造** |
| 附：转写勘误 | 只在用了转写时写。纠正不了的标「待核」，**不要臆改** |

## 使用提醒

- 笔记由 AI 整理，**仅供参考**，请务必对照课件原文与自己听课时的理解核对
- 有课堂转写时，重点判定是有依据的；**只有课件、没有转写时，「重点标注」只是根据课件猜的**——课件通常不写"这个要考"
- 智云课堂**有回放的课通常自带语音转写**，走 `scripts/fetch-lesson.js` 就能拿到，不必自己录音转写
- 机器转写会听错术语（实测：`程度`→`成都`、`一人公司`→`艺人化的公司`、`起号`→`洗好`），所以有勘误表这一节
