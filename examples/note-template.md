# 笔记模板（v2 · 框架优先 + 双轨分层 + 按段定位）

整理输出的标准模板。同学也可以直接复制本模板，自己往里填。

````markdown
---
course: <课程名>
lecture: <第NN讲 / 课时名>
teacher: <教师名>
date: <YYYY-MM-DD>
sub_id: <平台选课标识>
format: v2          # 框架优先 + 双轨分层 + 按段定位
persona: <按课程名自动推断的行业视角，例如：内容平台操盘手 / 文献学学者 / 资深工程师>
proofread: false
tags: [<课程名>, 课堂笔记]
created: <YYYY-MM-DD>
---

# <课程名> · <第NN讲>

> **【课】** = 老师这节课实际讲的，可回平台核对。**【延】** = 以 `persona` 视角补的，**不是本课内容，不标重点、不进考核依据**。
> 定位一律按**段**给（约一节课 40 分钟）。要精确回听时看每段末尾那一行 `> 回听：…`。
````

## 填写说明

| 板块 | 怎么写 |
|---|---|
| 头部 `sub_id` | 位置指针，回听时的精确跳转锚点 |
| `persona` | 由 AI 按课程名自动推断；推断仅用于口补，不影响其它任何内容 |
| 骨架 | 必填；是这份笔记区别于"散点清单"的关键。先有骨架再写正文 |
| 第 N 段 | 段内**成块叙述**，不要一行一条散点；秒级指针只出现在每段末尾的 `> 回听：` |
| `【课】` | 老师实际讲的。出现时**必带依据**（已在某段引用、将在重点引用、或有课件文字引用） |
| `【延】` | 以 persona 视角补的延伸。**不得作为重点依据**；只在文档草稿里供你交叉理解，不进背诵笔记 |
| 重点 | 一节课通常 3–4 条 ★，**写得出依据才标**。依据只能是【课】，不能是【延】 |
| 易混易错点 | 概念重的课程（古代汉语、数理）保留这一节；自媒体等不强调。**不写可省略** |
| 待办 | 课程有作业/预习要求才写 |
| 遗漏 | **如实填写**，拿不到就写拿不到，**绝不编造** |
| 转写勘误 | 只在用了转写时写。纠正不了的标「待核」，**不要臆改** |

## 使用提醒

- **这份笔记能用的前提：标注可追溯**。每一句有依据的话都能回到 `sub_id` + 时间戳在平台核对。
- 有课堂转写时，重点判定是有依据的；**只有课件、没有转写时，重点判定属推测**（头部依据行里写明）。
- **【延】不计入重点的依据**，但可以算摘要。期末考前背重点时忽略所有【延】即可。
- 智云课堂**有回放的课通常自带语音转写**，走 `scripts/fetch-lesson.js` 就能拿到。
- 机器转写会听错术语（实测：`程度`→`成都`、`一人公司`→`艺人化的公司`、`起号`→`洗好`），所以有勘误表这一节。
- 笔记由 AI 整理，**仅供参考**，请务必对照课件原文与自己的理解核对。
