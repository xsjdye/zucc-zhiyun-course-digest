# 笔记模板

整理输出的标准模板。同学也可以直接复制本模板，自己往里填。

```markdown
# <课程名> · <课时 / 章节名>

> 整理时间：<YYYY-MM-DD> ｜ 来源：学在城院·智云课堂 ｜ 整理方式：AI 辅助
> 重点判定依据：<课件文字 ／ 课件文字 + 课堂录音>

## 一、知识点梳理
- **<知识点 1>**：一句话说明
- **<知识点 2>**：一句话说明

## 二、重点标注
- ★ <重点 1>（只写你**看得到**的依据：课件加粗 / 单独成页 / 篇幅最大 / 目录与小结都出现 / 录音里老师明确说"要考"）
- ★ <重点 2>

## 三、易混易错点
- **<A> vs <B>**：区别是……

## 四、课后待办
- [ ] <作业 / 预习要求>

## 五、本次遗漏
- <未获取到的资料，如某段录音、某页课件；如无则写"无">
```

## 填写说明

| 板块 | 怎么写 |
|---|---|
| 一、知识点梳理 | 用自己的话说清"是什么"，别照抄课件原文 |
| 二、重点标注 | 必须**给出看得到的依据**，不能只打一个 ★；没有录音就别写"老师说重要" |
| 三、易混易错点 | 只有确实存在易混概念时才写；没有可省略 |
| 四、课后待办 | 课程有作业/预习要求才写；没有可省略 |
| 五、本次遗漏 | **如实填写**，拿不到就写拿不到，**绝不编造** |

## 使用提醒

- 笔记由 AI 整理，**仅供参考**，请务必对照课件原文核对
- **没有课堂录音时，「重点标注」只是根据课件猜的**——课件通常不写"这个要考"，老师嘴上的强调 AI 听不到
- 想让重点更准：把课堂录音（或录音转出的文字）一起给 AI，并在「重点判定依据」里注明
